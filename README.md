📖 About The Project

Hi there! 👋 This is my first project built with HTML, CSS and JavaScript.

It's a simple Rock Paper Scissors game where you play against the computer. You pick one option, the computer picks randomly, and the game decides who wins. Building it helped me understand how a webpage's structure, style and logic work together.

🎮 The rules: ✊ Rock beats ✌️ Scissors  |  ✌️ Scissors beats ✋ Paper  |  ✋ Paper beats ✊ Rock

✨ Features
🎯 Play against the computer, which makes a random choice every round
🖼️ Clickable image buttons for Rock, Paper and Scissors
🏆 Instantly shows whether you won, lost or tied
🎨 Clean, simple and beginner-friendly design
💻 Runs directly in the browser, with no installation needed
🛠️ Built With
Technology	Used for
HTML5	Page structure and layout
CSS3	Styling, colours and design
JavaScript	Game logic, random choice and result checking

🚀 How to Run
Clone the repository
bash
   git clone https://github.com/rg-byte/rock-paper-scissors.git
Open the folder in VS Code
Open index.html in your browser (or use the Live Server extension → Go Live)
Click Rock, Paper or Scissors and start playing! 🎉
